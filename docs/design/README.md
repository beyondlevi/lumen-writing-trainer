# Design

The approved boards (2026-10-11), in Brazilian Portuguese as drawn; the app ships English first
with Portuguese. 600 x 600 is the web app's square on the glasses; `04` shows the whole HUD while
the band writes, with Lumen's writing bar under the app.

| | |
| --- | --- |
| `01-home` | Streak, level and XP, best words per minute; Words, Phrases, Daily challenge, Progress |
| `02-level-trail` | The words' levels: done (stars), current, locked |
| `03-word-before-writing` | A word to write, its letters still to come |
| `04-glasses-while-writing` | The whole HUD while writing |
| `05-wrong-letter` | The band read another letter: outlined with an x, what it should be under it |
| `06-word-complete` | Every letter right: points, combo, the next word |
| `07-phrase-speed` | A phrase with live words per minute, time and accuracy |
| `08-round-result` | Stars, speed, accuracy, time, best combo, XP, letters to train |
| `09-progress` | Words per minute over the week, accuracy per letter |
